# 制作能力与双语 / Production and localization

## 中文

工具选择是能力判断，不固定某软件。遵守当前环境工具要求；只使用已提供、可调用的能力。

制作前查看[协作记录](user-collaboration.md)：当前应交付低保真方案、真实文案排版校样，还是高保真首稿。协作模式下G1–G4相关选择尚未解决时，不用整图渲染跳过决策；明确委托快速制作则按授权执行。展示草图与正式渲染是不同交付，不把其中一个冒充另一个。

- 输入有可编辑源文件且有对应编辑工具：优先保留图层与原始资产，确定性修改文字或布局，再核验导出。
- 只有区域图像编辑：明确编辑目标与范围，使用实际支持的区域约束，核验区域内与区域外；不承诺精确文字或零漂移。
- 只有整图生成：适合概念、背景和氛围探索；不能据此承诺“其他像素完全不变”或受保护资产完全准确。
- 无图像工具或缺关键原件：交付授权范围内的简报、方向、版式规格、文案或合成说明，注明未完成成图。不把文案中的品牌名伪装成原Logo。

能力记录保持简短：输入类型、可用工具、选择方法、无法保证项、预计交付状态。缺价格只影响价格区，缺商品原图影响资产验收，不阻断独立的策略工作。

双语适配：
0. 在G4用完整母本预排各语言，至少检查最长文本的空间风险；G5可先评审一个母版，稳定后制作其余版本。用户要求同时看多语时同时提供；母版批准不等于其他语言的文字与可读性也已通过。
1. 建立信息项ID与中文、英文批准母本的对应关系，保留产品名、所有必需卖点、价格、完整日期及CTA。缺译文时可拟稿并标注未批准，不冒充原母本。
2. 两版共享主张和品牌，允许不同换行和模块高度。优先语义自然的断行、减少装饰、调整授权布局，不拆固定词组，不无限缩字号。
3. 冻结布局与长文本冲突时，先尝试范围内重排；仍冲突则给出具体选择，不私改批准文案。
4. 核对数字、单位、空格、大小写、标点、日期与行动含义。文字识别工具只能辅助，不能代替母本对照和人工可读性检查。
5. 原尺寸、任务指定缩略宽度和手机观看情境分别验收。模板320px优先于通用约300px；像素宽度不是所有平台规范。记录渠道规格来源与核验日期，未知写未知。

## English

Choose by actual capability, not a fixed software brand, and obey environment tool requirements.

Before production, check the [collaboration record](user-collaboration.md): is this a low-fidelity proposal, a real-copy layout proof or a high-fidelity first draft? In collaborative mode, rendering must not bypass unresolved relevant G1–G4 decisions; explicit fast-path delegation permits execution within scope. Sketches and final rendering are different deliverables, not substitutes disguised as each other.

- With editable sources and an appropriate editor, preserve layers/assets, make deterministic copy or layout edits and verify export.
- Regional image editing: constrain the actual supported region and inspect both inside and outside it; no promise of exact text or zero drift.
- Whole-image generation: useful for concepts/scenery, not a guarantee of unchanged pixels or exact protected assets.
- No image tool or missing source assets: deliver an authorized brief, concepts, layout/copy or compositing instructions, explicitly without completed artwork. Typed brand names are not original logos.

Briefly record input type, available capability, selected method, limitations and delivery status. Missing price blocks its field, and missing product sources block asset approval, not independent strategy.

At G4, preflight complete locale copy, at least checking the longest text for fit. G5 may review one master before producing remaining locales; show multiple languages together when requested. Master approval does not establish other locales' copy accuracy or legibility.

Localization: map each information ID to approved Chinese/English copy, preserving all required fields. Label proposed translations as unapproved. Share intent and brand while allowing language-specific wrapping and module heights. Reflow, reduce decoration and adjust authorized layout before reducing font size; do not split fixed phrases. Resolve conflicts with frozen layouts by offering specific scope choices, never silently rewriting approved text. Verify numbers, units, spacing, case, punctuation, dates and CTA meaning. OCR assists but does not replace source comparison and readability review. Review native size, specified thumbnail width and mobile context; a 320px template overrides the approximate 300px default, neither is a universal platform rule. Record specification source/date or mark unknown.
